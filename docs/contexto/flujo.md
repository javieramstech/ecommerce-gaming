# Flujo de Trabajo y Definition of Done - JMSHOP

@docs/contexto/flujo-de-trabajo.md

## 1. Pasos de Maquetado SDD
1. **Estructura HTML5 Semántica:** Maquetado con `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
2. **Estilos TailwindCSS v3:** Maquetado utilitario responsive y modo claro/oscuro.
3. **Interactividad JS Vanilla:** Lógica para menú hamburguesa, toggle de tema, modales y formulario de contacto.

## 2. Definition of Done (DoD)
- Justificación técnica.
- HTML válido y 0 errores en consola JS.
- Verificación visual de 4 estados UI (Success, Loading, Empty, Error).
- Comprobación responsive en escritorio y móvil.
