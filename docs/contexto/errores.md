# Errores Conocidos y Gotchas de Maquetado - JMSHOP

@docs/contexto/errores-conocidos.md

## Gotchas Principales
1. Prevención de scroll horizontal roto (`overflow-x-hidden`).
2. Atributos `alt` obligatorios en imágenes de tarjetas.
3. Uso estricto de `<button>` y `<a>` para elementos interactivos.
4. Contraste accesible en temas claro y oscuro.
5. Evitar IDs duplicados en el DOM.
